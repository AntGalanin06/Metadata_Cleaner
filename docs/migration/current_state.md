# Текущее состояние проекта Metadata Cleaner

## Архитектура приложения
- **Ядро очистки (`metadata_cleaner/cleaner`)**: диспетчер `MetadataDispatcher` определяет тип файла и делегирует обработку специализированным обработчикам (`image`, `pdf`, `office`, `video`). Каждый обработчик создает резервную копию, очищает метаданные и возвращает подробный результат (`CleanResult`).
- **Настройки (`metadata_cleaner/services/settings_service.py`)**: хранение пользовательских настроек (тема, язык, стратегии резервного копирования, параметры очистки по типам файлов, размеры окна) в JSON-файле в профиле пользователя. Используются значения по умолчанию из реестра метаданных.
- **Реестр метаданных (`metadata_cleaner/cleaner/metadata_registry.py`)**: единый источник описаний полей метаданных, категорий, приоритетов и значений по умолчанию для UI и логики очистки.
- **GUI на Flet (`metadata_cleaner/gui`)**: приложение `MetadataCleanerApp` со слоями UI-компонентов (панели действий, карточки файлов, прогресс, детальные результаты, настройки). Использует диалоги и файловые пикеры Flet, локализацию через `metadata_cleaner/gui/localization.py`.
- **CLI (`metadata_cleaner/cli.py`)**: обертка над диспетчером с аргументами командной строки, опциями сохранения отдельных полей, конфигурацией логирования и безопасным выводом для Windows.
- **Запуск и сборка**: `run.py` для dev-запуска GUI, `build.py` — кроссплатформенный PyInstaller-сборщик с доставкой FFmpeg и подготовкой ассетов, `Makefile`/`scripts` для линтинга и тестирования.

## Функциональные возможности
- Очистка метаданных для изображений (JPEG/PNG/HEIC/GIF), документов Office (DOCX/PPTX/XLSX), PDF и видео (MP4/MOV).
- Настраиваемые политики удаления для каждой категории метаданных (автор, GPS, камера, теги и др.), резервное копирование и режимы сохранения.
- Поддержка пакетной обработки, отображение прогресса и статистики, детализированные отчеты по каждому файлу, уведомления.
- Локализация на русском и английском, темы (light/dark/system), адаптивный интерфейс с GridView.
- Интеграция с CLI, возможна headless-очистка без GUI.

## Зависимости и окружение
- Python `>=3.11,<3.14` (Poetry), основная зависимость — `flet` для UI.
- Работа с метаданными: `piexif`, `Pillow`, `pillow-heif`, `python-docx`, `python-pptx`, `openpyxl`, `pypdf`, `hachoir`.
- Dev-инструменты: `pytest`, `ruff`, `black`, `mypy`, `bandit`, `semgrep`, `pip-audit`, `safety`.
- Сборка бинарников через PyInstaller; для видео поставляется `bundled_ffmpeg`.

## Наблюдения и ограничения
- Жесткая привязка UI-логики к Flet, обработка пользовательских действий синхронно внутри `MetadataCleanerApp`.
- Множество взаимодействий с файловой системой напрямую из GUI (обновление состояния, работа с FilePicker), что усложняет разделение на клиент/сервер.
- Настройки и реестр тесно связан с Python-классами и Enum; потребуется API для передачи клиенту.
- Сборка ориентирована на PyInstaller; Linux-пакеты страдают от зависимостей Flet и системных библиотек.
- Поддержка Python 3.14 отсутствует из-за ограничения в `pyproject.toml`.

## Пункты для переноса в новую архитектуру
- Функциональность обработчиков файлов и их тесты.
- Гибкая конфигурация очистки и резервных копий, включая хранение пользовательских настроек.
- CLI-режим (возможная адаптация под новую архитектуру).
- Процесс отображения прогресса, статистики и детальных результатов (через API/IPC).
